    本文旨在通过 Servlet 和网页，介绍基于 Java 的 Web 编程基础。阅读本文并测试其中的示例后，读者应能掌握 Java Web 编程的基本概念。

    为更好地理解文中提供的练习，参考文档[《基于Servlet和JSP页面的Java Web编程入门》（2002）]将有所帮助。某些章节开头的阅读建议中提到了该文章。下文将该文档简称为[ref1]。

    该文档可通过多种方式利用：

    1. 安装工具，从本文档网站下载代码，并进行提供的测试。初学者采用这种方法将一无所获。而经验丰富的开发人员，如果仅对测试 Eclipse / WTP 开发环境感兴趣，则可以这样做。
    2. 安装工具，按照文档指引操作，并通过复制粘贴文档内容来完成建议的测试。无需阅读文档[ref1]。 通过这种方式，您将开始掌握Web开发的基础知识，但某些细节仍会显得晦涩难懂或难以捉摸。如果希望快速入门，并计划在日后编写个人应用程序时再深入学习（届时可能参考[ref1]以外的其他文档），这是一种可行的方法。
    3. 操作与方法2相同，但在建议时阅读[ref1]。这种较慢的方法虽能消除方法2中的一些晦涩和神秘之处，但无法为独立开发做好充分准备，因为通过复制/粘贴获得的代码未必能被真正理解。
    4. 操作与方法3相同，但需自行输入所有代码。这显然耗时更长且更为繁琐，但非常有效。 输入代码时必须仔细阅读，这会促使你关注代码细节，从而开始理解其含义。这种手动抄写很少能完全避免抄写错误。这些错误会被Eclipse的各种工具标记出来，促使读者反思自己编写的代码，从而加深理解。

    本文摘录了2005年1月发表的一篇题为《使用Eclipse和Tomcat进行Java Web开发》的文章的大部分内容，该文章可通过网址[http://tahe.developpez.com/java/eclipse/]查阅。本文相较于该文章的补充内容如下：

    • 使用Eclipse的WTP插件进行Web应用程序开发，
    • 对文档进行了重组，重点突出了三层架构（MVC），而原文档对此仅略有提及，
    • 提供了一个使用SGBD数据的MVC三层Web应用程序示例。

    一个三层Web应用程序具有以下结构：

    • [dao]层负责数据访问，通常是存储在SGBD中的持久化数据。但也可能是来自传感器、网络等的数据
    • [metier]层实现应用程序的“业务”算法。该层与任何形式的用户界面均相互独立。 因此，它必须能够同时适用于控制台界面、Web 界面以及富客户端界面。这意味着该层必须能够在脱离 Web 界面的情况下进行测试，特别是通过控制台界面进行测试。这通常是架构中最稳定的层。无论用户界面如何变更，或获取应用程序运行所需数据的方式如何改变，该层均保持不变。
    • [web]层即Web界面，它允许用户控制应用程序并接收相关信息。

    文章 [http://tahe.developpez.com/java/eclipse/] 仅提供了仅限于 [web] 层的 Web 应用程序示例。本文则提供了一个使用这三个层的示例。

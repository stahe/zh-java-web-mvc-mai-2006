# Java MVC 网页开发

本仓库包含一系列资源和练习，旨在帮助您学习基于 **Servlet** 和 **JSP 页面** 的 Java 网页开发基础。

> [!提示]
> **访问完整课程：** [https://stahe.github.io/zh-java-web-mvc-mai-2006/](https://stahe.github.io/zh-java-web-mvc-mai-2006/)

---

## 📖 简介

本资源旨在通过 **三层 MVC 架构** 讲解 Java Web 编程的基础概念。本文基于 2005 年 1 月的《使用 Eclipse 和 Tomcat 进行 Java Web 开发》一文，并增加了以下内容：
* **Eclipse WTP** 插件的使用。


* 基于**三层架构**的结构。


* 一个使用**数据库管理系统（DBMS）**的实践示例。



## 🏗️ 应用程序架构

该项目采用三层结构，以确保代码的模块化和稳定性：

**Web层 [web]** | 允许用户控制应用程序并接收信息的界面。

**业务层 [business]** | 包含业务逻辑。该层独立于界面（Web、控制台等），是稳定性最高的层。

**数据访问层 [DAO]** | 管理对持久化数据（DBMS）或外部数据（传感器、网络）的访问。


## 🚀 学习方法

针对本内容有多种学习方法，从最快捷到最有效：

1. **专家方法：** 安装工具并直接测试下载的代码（仅适用于熟悉 Eclipse/WTP 的开发者）。


2. **快速方法：** 按照文档复制并粘贴代码。此方法可让你快速入门，但某些概念可能仍会显得“晦涩难懂”。


3. **引导式方法：**与方法 2 相同，但在文档建议时，请随时查阅参考文档 `[ref1]`（Java Web 编程入门）。


4. **推荐方法：**仔细阅读文档，手动输入全部代码。这是理解逻辑并纠正自身语法错误的最有效方法。
